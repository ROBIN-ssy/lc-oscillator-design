## 1. 为什么"结构上可行"(三点式判据)

以最常见的单管考毕兹接法为例:LC 谐振回路三个端点分别接晶体管三个极,
**两个分压电容的公共点接发射极(反馈节点),电感接集电极—(交流地)**。

满足两个条件就能自激:
1. **相位条件**:发射极所接两个电抗元件同为电容(C1、C2),即"电容三点式"——反馈极性天然为正,无需额外倒相;
2. **振幅条件(起振条件)**:环路增益 |A·F| > 1(巴克豪森判据)。

振荡频率(两电容串联后再与 L 并联谐振):

```
f0 = 1 / ( 2π · √( L · Cser ) ),   Cser = C1·C2/(C1+C2)
```

原图 C14=C15=100nF → Cser = 50nF。若配合常见电感:

| L | f0(用 2×100nF) | 评价 |
|---|---|---|
| 470µH | ≈ 32.8 kHz | 低 Q、偏置易停振 |
| 1 mH | ≈ 22.5 kHz | 勉强可用,需电感 Q 高 |
| 10 mH | ≈ 7.1 kHz | 电感体积大、寄生电容大 |
| **建议改小电容** | —— | 100nF 级分压电容在 kHz 以上不实用,且会把反馈节点阻抗拉得很低 |

> **关键点**:原图 100nF 分压 + "未标注电感"组合本身不自洽。
> 若想工作在数百 kHz~MHz,应把分压电容改到 nF 级(见第 4 节修正方案)。

## 2. 原图逐项问题清单(读图结果)

| # | 原图项 | 问题 | 处理 |
|---|---|---|---|
| 1 | 未见电感 L 数值 | LC 振荡器**必须有**谐振电感,缺失则不可能振荡 | 补 L1 |
| 2 | C14/C15 = 100nF | 谐振频率被压到 kHz 级,或需 mH 级电感;分压阻抗过低会吃掉环路增益 | 改为 nF 级(或按目标频率反算) |
| 3 | R11=43k, R12=10k | VB ≈ 5×10/53 ≈ 0.94 V,发射极电位仅 ~0.25 V,IC 仅 ~0.25 mA,起振余量小、温漂敏感 | 上偏置改 27k(或保留 VR11 微调),VB≈1.35 V |
| 4 | R13=1k 直接作集电极负载 | 若按"共基 + 电感馈电"接法,1k 电阻会与谐振回路并联、严重降低 Q;两种接法需二选一 | 修正方案:集电极经 L1 馈电,去掉 R13 |
| 5 | C13=22µF 发射极旁路 | 若反馈节点就是发射极,此电容会把反馈信号对地短路 → **停振**(常见接错点) | 共基方案中发射极不并旁路电容(仅 Re 提供直流),或按共射变体重新确认 |
| 6 | 两路去耦 VCC_5V / VEE_5V | 本振荡器单 5V 即可;若 VEE 仅给其它电路,与本单元无关 | 保留 VCC 去耦,其余标注可删 |
| 7 | OUT 直接引出 | 谐振回路输出阻抗高(几十 kΩ),带负载能力差 | 加 Cout 耦合 + 提示需高阻负载/加缓冲 |
| 8 | VR11=10k | 位置不明;宜作"上偏置微调"控制静态点/振幅 | 与 R11 串联作微调 |

```
              VCC  +5V
               │
   R11 27k ────┤          C_dec 100n (靠近L1,再并470n/10µ亦可)
   (可串VR11 10k微调)        │
               │            ┴ GND
               │
     Cb 100n ──┤
     (基极交流接地)│
               │
   B ● ────────┤
               │
      Q1 NPN    │  L1 47µH(从VCC馈电,兼作谐振电感)
   (共基接法)    │      │
               │      ● C 集电极 ── Cout 100n ──● OUT(输出)
               │      │
               │  C1 1nF
               │      │
   Re 1k ── E ● ──────┘      (E = 反馈节点,两分压电容公共点)
               │
               └── C2 1nF ── GND

   GND ───────────────────────────────
```

| C(集电极) | L1 下端,Q1 集电极,C1 上端,Cout 上端 |

## 4. 设计验算(修正方案)

**静态工作点**(VB≈1.35 V,设 VBE=0.65 V):
- VE = VB − 0.65 ≈ 0.70 V → IE ≈ 0.70 mA,IC ≈ 0.70 mA
- VC(DC) = VCC − IE·RL1(DC≈0) ≈ 5 V,VCE ≈ 4.3 V → 放大区 ✓
- gm = IC/26mV ≈ 27 mS

**谐振频率**:
- Cser = 1nF×1nF/(1nF+1nF) = 0.5 nF;L1 = 47µH
- f0 = 1/(2π·√(47µ·0.5n)) ≈ **1.04 MHz**

**起振余量估算**:
- 谐振回路等效并联电阻 Rp ≈ Q·XL = Q·2πf0·L1;取 Q≈60 → Rp ≈ 19 kΩ
- 环路增益粗略 ≈ gm · Rp · (C1/(C1+C2) 分压系数≈0.5) ≈ 27mS·19k·0.5 ≈ **250 ≫ 1**
- 起振极可靠,幅度由非线性自动限幅,谐振回路滤除谐波后接近正弦

**频率调整表**(保持 C1=C2,或按需换 L1):

| 目标 f0 | L1 | C1=C2 |
|---|---|---|
| ≈ 1.04 MHz | 47µH | 1nF |
| ≈ 500 kHz | 100µH | 1nF |
| ≈ 104 kHz | 47µH | 10nF |
| ≈ 20~25 kHz | 1mH | 100nF(保留原值) |

**输出**:OUT 端建议接 ≥10kΩ 负载;若驱动低阻/长线,请加一级射极跟随器(NPN+10k 上拉或运放缓冲),否则会拉偏谐振频率与停振。
