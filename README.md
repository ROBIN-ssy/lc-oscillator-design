# LC 振荡器：一张电路图的可行性审查

拿到一张画好的 LC 振荡器原理图，先不焊，先回答一个问题：**它能不能振？**

这个仓库是那次审查的完整记录 —— 从读图、找问题、给修正方案，到用 LTspice 把两个版本都跑一遍验证。

---

## 结论速览

| 项目 | 结论 |
|---|---|
| 电路类型 | 电容三点式 LC 正弦振荡器（考毕兹 Colpitts 类），**原理上可行** |
| 原图是否"必然能振荡" | **不能保证** —— 见下面 8 条问题 |
| 修正方向 | 补明确电感、把分压电容降到 nF 级、抬高基极偏置、去掉会短路反馈节点的发射极旁路电容、加输出耦合 |
| 修正后方案 | 单 +5 V 共基考毕兹，目标 f0 ≈ 1.04 MHz |
| **实测结果** | 原版 **182.4 kHz**，修正版 **1.033 MHz**（见「仿真验证」） |

---

## 原图的 8 个问题

摘自 [`analysis/LC_Osc_Feasibility_and_Schematic.md`](analysis/LC_Osc_Feasibility_and_Schematic.md)：

| # | 问题 | 后果 |
|---|---|---|
| 1 | 未见电感 L 的数值 | LC 振荡器**必须有**谐振电感，缺失则不可能振荡 |
| 2 | 分压电容 100nF | 谐振频率被压到 kHz 级；分压阻抗过低会吃掉环路增益 |
| 3 | 偏置 43k/10k，VB ≈ 0.94 V | IC 仅 ~0.25 mA，起振余量小、温漂敏感 |
| 4 | R13=1k 直接作集电极负载 | 会与谐振回路并联、严重降低 Q |
| 5 | C13=22µF 发射极旁路 | 若反馈节点就是发射极，此电容会把反馈对地短路 → **停振** |
| 6 | 两路电源 VCC/VEE | 本振荡器单 5 V 即可 |
| 7 | OUT 直接引出 | 谐振回路输出阻抗几十 kΩ，带负载能力差 |
| 8 | VR11 位置不明 | 宜作上偏置微调 |

> 第 5 条是这类电路最常见的接错点：**发射极一旦并了旁路电容，反馈就被短路了**。

## 仿真验证

文档里只有纸面计算。为了确认，**两个版本都实际跑了 LTspice 26.0.2**。

### 1. 原版：`sim/LC振荡器.asc`

原电路 `L1 = 15µH`、分压电容 `100nF`、`+12 V`、三只 2N3904。

| 项目 | 值 |
|---|---|
| 实测振荡频率 | **182.4 kHz** |
| 理论值 `1/(2π√(15µH × 50nF))` | 183.8 kHz |
| 误差 | **0.8%** |
| 振荡幅度 | ±5.36 V（12 V 电源），已进入强限幅 |
| 遗留问题 | 日志有 `WARNING: Node n003 / n005 is floating.` |

**这条结果正好印证了分析文档的第 2、3 条判断** —— `100nF` 级分压电容配普通电感，只能振荡在 kHz 级。
"能不能振"和"振在什么频率"是两个问题，原电路是前者可以、后者不符合预期。

### 2. 修正版：`sim/Colpitts_1MHz.cir`

按分析文档第 3 节的方案重画：`L1 = 47µH`、`C1 = C2 = 1nF`、单 `+5 V`。

| 项目 | 值 |
|---|---|
| 实测振荡频率 | **1.0332 MHz** |
| 理论值 `1/(2π√(47µH × 0.5nF))` | 1.0382 MHz |
| 误差 | **0.5%** |
| 起振过程 | 270 µs 时幅度 0.52 V → 稳定在 5.05 V 限幅 |

**验证方法**：`sim/analyze_raw.py` 直接解析 LTspice 的 `.raw` 二进制，按末尾 20% 段做过零检测测频。

```bash
# 跑仿真（LTspice 批量模式）
LTspice.exe -b -Run sim/Colpitts_1MHz.cir

# 分析波形：列出所有节点的振荡幅度与频率
python sim/analyze_raw.py sim/Colpitts_1MHz.raw

# 只看某一个节点
python sim/analyze_raw.py sim/Colpitts_1MHz.raw V(out)
```

## 一个反常的地方

嘉立创 EDA 导出的元件区（`eda/lc_osc_region_final.json`）里，板子上实际贴的是
**`0603B682K500NT` = 6.8 nF**，而不是分析文档里写的 `100nF`。

和文档建议的"应改到 nF 级"吻合 —— 如果这块板是改版之后的，那这份"改前 → 改后"的对照
比最终成品更能说明设计是怎么收敛的。

## 为什么这个仓库值得看

不是因为它做成了一个振荡器，而是因为它展示了一件更常见的事：

> **有人递给你一张电路图，你需要在焊之前指出哪几个地方会做不成。**

纸面计算能给出结论，但要确认结论是否成立，得把电路真的跑一遍。
这两次仿真一共花不到 2 秒 —— 比打样等 3 天便宜多了。
